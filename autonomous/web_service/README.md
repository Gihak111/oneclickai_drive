
# 라즈베리파이 RC카 프로젝트 코드 설명 (2025.09.02 최신)

이 프로젝트는 라즈베리파이 기반의 RC카를 제어하고, 카메라 스트리밍 및 키 입력을 통한 원격 제어 기능을 제공합니다.



## 파일별 역할

### 1. `camera_stream.py`
- 라즈베리파이 카메라(Picamera2)를 이용해 실시간 영상 스트림을 생성합니다.
- MJPEG 스트림 및 최신 프레임을 제공하는 클래스(`CameraStream`)를 정의합니다.
- 영상 프레임을 JPEG으로 인코딩하여 외부에서 접근할 수 있도록 준비합니다.

### 2. `motor_cont.py`
- 라즈베리파이의 GPIO 핀을 이용해 모터(좌/우)와 서보모터를 제어합니다.
- 전진, 후진, 좌회전, 우회전, 정지 등 RC카의 기본 동작을 함수로 제공합니다.
- `drive()` 함수는 입력 플래그에 따라 모터와 서보의 동작을 결정합니다.
- `set_params()` 함수로 각도/속도 파라미터를 외부에서 동적으로 변경할 수 있습니다.

### 3. `rpi_servo.py`
- 서보모터 제어를 위한 PWM 신호를 생성합니다.
- 각도를 입력받아 해당 각도에 맞는 PWM 듀티값을 계산하고, 서보모터를 움직입니다.
- 리눅스 sysfs PWM 인터페이스(`/run/pwm18_path`)를 통해 하드웨어 PWM을 직접 제어합니다. (`pwm18.service` systemd 서비스가 실행 중이어야 합니다.)

### 4. `key_cont.py`
- 키 입력(예: w, a, s, d 등)을 받아 RC카의 동작을 결정합니다.
- 입력된 키 조합에 따라 `motor_cont`의 `drive()` 함수를 호출하여 RC카를 제어합니다.
- 예를 들어, 'w'는 전진, 'a'는 좌회전, 's'는 후진, 'd'는 우회전을 의미합니다.

### 5. `test_flask.py`
- Flask 웹 서버를 통해 카메라 영상 스트리밍(MJPEG)과 키 입력 API를 제공합니다.
- 웹 UI에서 키 입력을 받아 RC카를 원격 제어할 수 있습니다.
- `/stream.mjpg` 엔드포인트로 실시간 카메라 영상을, `/keys` 엔드포인트로 키 입력을 처리합니다.
- 각도/속도 입력값이 바뀌면 `/set_params`로 motor_cont 파라미터가 실시간 반영됩니다.

---

## 전체 구조 요약
- **카메라 스트림**: `camera_stream.py`에서 MJPEG 스트림 생성 → `test_flask.py`에서 웹으로 제공
- **모터/서보 제어**: `motor_cont.py`, `rpi_servo.py`에서 하드웨어 제어
- **키 입력 처리**: `key_cont.py`에서 키 입력 해석 및 동작 결정
- **웹 인터페이스**: `test_flask.py`에서 영상 확인 및 키 입력 전송 및 파라미터 실시간 조정
