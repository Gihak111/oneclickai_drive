  1. 데이터 모으기 — 저장 ON (S) → 방향키로 코스를 여러 번 주행. 버튼을 누르고 있는 동안만 그 라벨(go/left/right/brake)로 autonomous/image/에 저장됩니다 (누르는 순간 1장, 계속 누르면 실시간으로 계속).
  2. 학습 — PC에서 python autonomous/model/model.py → 생성된 keras_model.tflite를 autonomous/model/에 넣기.
  3. 자율주행 — 모델 다시 불러오기 → 자율주행 시작 (Z). 방향키를 누르면 즉시 수동으로 돌아옵니다.
