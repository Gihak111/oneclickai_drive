# motions/ — 동작(모션) 저장 폴더

웹 UI의 **동작 만들기**(`http://<IP>:8080/motion`) 페이지에서 만든 동작이
이 폴더에 JSON 파일로 저장됩니다.

## 파일 포맷

```json
{
    "name": "인사하기",
    "loop": false,
    "keyframes": [
        {"time": 0.0, "angles": [90, 90, 90, 90, 90, 90, 90, 90, 90, 90, 90, 90]},
        {"time": 0.5, "angles": [95, 80, 90, 90, 90, 90, 90, 90, 90, 90, 90, 90]}
    ]
}
```

- `time`: 키프레임 시각 (초). 재생 시 키프레임 사이를 ESP32가 보간으로 연결합니다.
  반복 동작은 전 구간 선형(등속)으로 이어 붙이고, 일반 동작은 첫 구간 ease-in / 마지막 구간
  ease-out(구간이 하나면 코사인)으로 시작과 끝만 감속합니다.
- `angles`: 서보 12개의 **실제 각도** (0~180도). 인덱스 순서는 README의 서보 맵핑표와 동일합니다.
  - 0=FL Hip, 1=FL Knee, 2=FL Wave, 3=FR Wave, 4=FR Hip, 5=FR Knee,
    6=BL Hip, 7=BL Knee, 8=BL Wave, 9=BR Wave, 10=BR Hip, 11=BR Knee
- `loop`: true면 마지막 키프레임에서 첫 키프레임으로 되돌아가 반복 재생합니다.
  복귀에 걸리는 시간은 첫 키프레임의 `time`이 0보다 크면 그 값, 0이면 **마지막 구간의
  시간**(마지막 두 키프레임의 간격)입니다. 편집기가 첫 키프레임을 0초로 만들므로 보통은
  키프레임 간격과 같은 시간으로 자연스럽게 순환합니다. 반복 동작은 키프레임이 2개 이상이어야 합니다.
- 재생 시작 시 현재 자세에서 첫 키프레임으로 가는 진입 시간은 최소 0.6초입니다
  (바닥에 누운 자세에서 시작해도 튀지 않도록). 키프레임 사이 시간 간격은 0.05초 이상이어야 합니다.

## 동작을 만드는 가장 쉬운 방법 (퍼펫티어링)

각도를 직접 계산할 필요 없이, 웹 UI에서:

1. **[토크 끄기]** — 모터에 힘이 빠집니다.
2. 손으로 로봇의 자세를 원하는 모양으로 잡습니다.
3. **[현재 자세 캡처]** — 실제 서보 각도가 읽혀서 키프레임으로 추가됩니다.
4. 2~3을 반복해서 키프레임을 쌓습니다.
5. **[토크 켜기]** 후 시간 값을 조정하고 **[재생]**으로 확인합니다.

주의: 각도는 로봇의 실제 서보 각도이므로, 무리한 자세(다리끼리 충돌 등)를
키프레임에 넣으면 하드웨어에 부담이 갈 수 있습니다. 처음에는 긴 시간(느린 속도)으로
재생하며 확인하세요.
